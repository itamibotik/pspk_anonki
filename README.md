# 📢 pspk_anonki — Анонимный студенческий бот

Многофункциональный анонимный бот для Telegram:
- Анонимные анонки с модерацией
- Реакции (лайки/дизлайки)
- Временные анонимки (10 минут / час / сутки)
- Обмен шпорами, конспектами и файлами
- Подписи админов "админ 1", "владелец" и др.
- Еженедельная воскресная сводка лучших анонок

## 📦 Установка
1. Установить зависимости:
pip install -r requirements.txt


2. Настроить .env файл (смотри `.env.example`)


3. Запустить:
python main.py
